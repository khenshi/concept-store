# Kapwesto Brand Assets

Place approved brand artwork in this directory using these stable filenames:

- `logo.svg` — full horizontal logo for light backgrounds
- `logo-dark.svg` — full horizontal logo for dark backgrounds
- `mark.svg` — compact square symbol for navigation and small placements
- `favicon.svg` — browser icon
- `social-card.png` — optional 1200 × 630 social sharing image
- `icon-192.png` and `icon-512.png` — optional future PWA icons

Prefer SVG for logos and marks. Keep text legible, preserve transparent
backgrounds, and do not rename these files after components begin referencing
them. Until approved artwork is supplied, the application uses its built-in
Kapwesto “K” fallback mark.
