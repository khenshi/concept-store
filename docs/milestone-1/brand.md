# Brand Guidelines

## Style

Modern, clean, professional B2B SaaS for retail operations.

Prioritize **clarity, consistency, usability, and speed**. Avoid gradients, glassmorphism, excessive shadows, animations, and overly colorful interfaces.

## Colors

| Usage         | Color     |

| Primary Dark  | `#047857` |
| Primary Light | `#D1FAE5` |

| Muted Text    | `#64748B` |
| Border        | `#E2E8F0` |
| Success       | `#16A34A` |
| Warning       | `#F59E0B` |
| Error         | `#DC2626` |

Use green as the main brand color while keeping most surfaces neutral.

## Typography

Use **Inter**.

## Core Rule

Choose the **simplest, clearest, and most consistent design**. Do not introduce new colors, fonts, icon libraries, or design patterns without a clear requirement.
