# Sales Reports overview distillation

Approved scope for the Reports overview refinement:

- Make the period result the first visual answer by promoting net recorded sales
  and reducing equal-weight KPI treatment for supporting metrics.
- Replace full-size zero-value trend, weekday, payment, merchant, and product
  chart regions with compact, explicit empty states while preserving accessible
  exact-value data and non-empty chart behavior.
- Keep the existing report tabs, filters, role-scoped data, chart calculations,
  and API contracts unchanged.
- Update Reports component tests and module documentation, then archive this
  plan after implementation.

Explicit exclusions: no backend, schema, API, authorization, date-default, or
report-navigation changes.
