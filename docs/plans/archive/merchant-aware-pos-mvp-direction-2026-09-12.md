# Merchant-Aware POS MVP Direction

**Status:** Archived direction; not an active implementation plan
**Date:** September 12, 2026

This direction proposed the following delivery sequence:

1. Merchant profiles.
2. Products and branch inventory.
3. Online POS with merchant-attributed sales.
4. Merchant sales summaries and manual remittances.

It proposed deferring space profiles, occupancy assignments, commercial
agreements, rent and commission automation, formal settlements, merchant
self-service, offline POS, and SaaS billing.

This record is preserved only as product-planning history. Agents must not use
it as implementation scope. A new current implementation plan requires explicit
user instruction.
