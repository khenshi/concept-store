# Account Color Theme Expansion

**Status:** Approved and implemented September 23, 2026.

## Additional approved scope: Account color themes

Expand the personal account theme picker from four to fourteen themes: eleven light and three dark, using the names, anchors, contrast targets, persistence, document-wide application, picker behavior, and validation in the user-provided expansion plan. Preserve Graphite as default and existing preferences. No organization theme, system mode, or custom picker is included. Archive this section separately when complete; retain the inventory plan.


## Outcome

Fourteen complete semantic palettes, an additive account enum migration, a grouped picker, document-wide application, contrast checks, and account documentation.
