# Current Plan

## Sales report Overview layout refinement

Approved scope for the Reports Overview tab layout refinement:

- Make the period summary the clear first reading stop, followed by the primary
  sales trend and then grouped secondary breakdowns.
- Use spacing, structural dividers, and responsive chart groups to reduce the
  feeling of four equally weighted chart panels without changing report data,
  metrics, controls, or empty-state behavior.
- Keep staff and merchant Overview layouts aligned where their authorized data
  overlaps, while preserving merchant-specific wording and privacy.
- Update focused component tests and Reports module documentation, then archive
  this plan after implementation.

Explicit exclusions: no backend, schema, API, role authorization, report
totals, date behavior, tab behavior, or chart calculations.
