# Current implementation plan

Plan 12, [Performance, dependency and security qualification](pending/12-performance-security-qualification.md),
is approved and active as of October 27, 2026.

This qualification pass is limited to the approved pilot envelope of up to five
simultaneous staff across 1–2 organizations. It covers reproducible capacity,
dependency, application-security, financial-concurrency and runtime/proxy
evidence using disposable or explicitly approved targets.

Do not upgrade packages, add scanners/load frameworks, run intrusive production
traffic, alter payment/email recipients, or change infrastructure without a
separate approved scope. Route functional defects to their owning plans. Plan 11
has a committed route-recovery/confirmation slice and local automated gates;
remaining browser/PDF evidence stays visible for final acceptance. Pilot device
qualification remains deferred by user decision. Plan 14 owns release approval.
